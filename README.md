# ServNet – On-Demand Home Service Platform

ServNet is a web-based platform designed to connect customers with reliable and skilled service providers for various household services such as cleaning, plumbing, electrical work, and maintenance. The system offers a centralized solution where users can easily browse services, book appointments, and track service status in real time.

The platform includes role-based modules for customers and service providers. Customers can register, search for services, and book requests, while service providers can manage incoming bookings, update job status, and handle service schedules efficiently. The system also features real-time status updates, feedback and rating mechanisms, and a user-friendly interface to enhance transparency and service quality.

ServNet aims to simplify the process of finding trusted professionals, reduce manual effort, and improve communication between users and providers. The system is scalable and can be extended with features like online payments, location tracking, and advanced recommendations.

## 🚀 Features
- User registration and login (Customer & Service Provider)
- Browse and book services easily
- Real-time booking status tracking
- Service provider dashboard for managing requests
- Feedback and rating system
- Clean and user-friendly interface

## 🛠️ Tech Stack
- Frontend: Vanilla HTML, CSS, JavaScript
- Backend: Node.js,Express.js
- Database: MongoDB(via Mongoose)
- security: JWT & Bcrypt
  
## 📌 Modules
- Customer Module
- Service Provider Module
- Admin Module

## 📊 Functionality
- Customers can search and book services
- Providers can accept/reject requests and update status
- System maintains booking records and feedback

## 🔮 Future Enhancements
- Online payment integration
- AI-based recommendations
